Privacy Policy

Classroom Image Sync — last updated 20 August 2026

Summary

Classroom Image Sync is a command-line tool that runs on the user's own computer. It has no server, no database and no operator. It does not collect, transmit, sell or share anyone's data. The only network connections it makes are directly between the user's own computer and Google's APIs, using that user's own credentials.

What the application accesses

When the user authorises it, the tool reads — with read-only permission — the announcements, course-work materials and assignments of a Google Classroom course the user already belongs to, and downloads the image files attached to those posts from Google Drive. It has no ability to post, modify, delete or share anything in either service.

What is stored, and where

Everything stays on the user's own computer. Nothing is uploaded anywhere.

  • Downloaded images — written to a local folder chosen by the user.
  • A local manifest — the Drive file IDs, file names and post titles already downloaded, so repeat runs skip them.
  • An OAuth token — stored locally so the tool can run on a schedule without asking for a password. It is never transmitted anywhere except back to Google when refreshing access.
  • A local log file — a record of what each run downloaded.

What is not done

  • No data is sent to the developer or to any third party.
  • There is no analytics, telemetry, tracking or advertising.
  • Nothing is sold, rented or disclosed to anyone.
  • There is no hosted service that could hold user data.

Google user data and Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through Google APIs is used solely to provide the feature described above — saving the user's own Classroom image attachments to their own computer — and for no other purpose.

Retention and deletion

Because all data stays on the user's own machine, the user controls it entirely. Deleting the downloaded folder, the manifest and the stored token removes everything the tool has kept.

Revoking access

Access can be withdrawn at any time from Google Account permissions. Deleting the local token file also stops the tool from making any further requests.
