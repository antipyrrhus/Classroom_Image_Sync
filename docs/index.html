Classroom Image Sync

A personal command-line tool that saves image attachments from a Google Classroom course to a local folder.

What it does

Google Classroom has no way to bulk-download the pictures posted to a course. This tool lists the announcements, course-work materials and assignments in a single course, finds the Google Drive files attached to them, and downloads the images to a folder on the computer it runs on. It keeps a record of which files it has already fetched, so it can run on a schedule and only pick up what is new.

Who it is for

It is a single-user utility, run from the command line by the person who owns the Google account. There is no hosted service, no website to sign in to, and no shared instance. It runs entirely on the user's own machine.

What access it asks for

It requests read-only permission, and nothing more:

  • classroom.courses.readonly — read the course name
  • classroom.announcements.readonly — list announcements
  • classroom.courseworkmaterials.readonly — list materials
  • classroom.coursework.me.readonly — list assignments
  • drive.readonly — download the attached image files

It cannot post, edit, delete or share anything. The Drive scope is needed because Classroom attachments are stored as Drive files; the narrower drive.file scope only covers files an app created itself, which never includes attachments posted by someone else.
